# 环境情报准备(IPB)

## 步骤
1. 界定作战地域与关注环境要素。
2. 分析地形与气象对行动的影响。
3. 研判对手能力与可能行动。
4. 汇总形成情报态势与研判结论。

## 检查清单
- [ ] 环境要素覆盖完整
- [ ] 研判结论有依据

## 输出格式
- 情报态势研判报告（环境影响 + 对手研判 + 结论）

## 禁止事项
- 不涉及真实情报来源与涉密数据
