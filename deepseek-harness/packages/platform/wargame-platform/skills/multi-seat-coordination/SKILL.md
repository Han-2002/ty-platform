# 多席位协同计划

## 步骤
1. 明确各席位的职责与协同关系（指挥链）。
2. 定义协同消息类型与流转规则。
3. 制定并发任务分工，避免冲突与重复。
4. 设定协同节点与检查点。

## 检查清单
- [ ] 席位职责与指挥链一致
- [ ] 并发任务无冲突

## 输出格式
- 协同计划（席位分工表 + 消息流转 + 节点清单）

## 禁止事项
- 不涉及具体战术与武器操作
