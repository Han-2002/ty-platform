# OODA 决策循环

## 步骤
1. 观察(Observe)：收集态势信息。
2. 判断(Orient)：结合背景与目标解读态势。
3. 决策(Decide)：形成行动方案。
4. 行动(Act)：执行并回到观察形成闭环。

## 检查清单
- [ ] 每个环节均有明确输入与输出
- [ ] 循环节奏快于对手决策周期

## 输出格式
- 决策记录（态势摘要 + 判断结论 + 决策要点 + 行动项）

## 禁止事项
- 不涉及具体武器操作与涉密战术
