# 方案评估矩阵

## 步骤
1. 确定评估准则（如可行性、资源消耗、达成度）。
2. 为各准则赋予权重，权重之和为 1。
3. 对每套候选方案逐准则打分。
4. 加权汇总得分并排序择优。

## 检查清单
- [ ] 权重之和为 1
- [ ] 打分口径一致

## 输出格式
- 评估矩阵表（方案 × 准则 + 加权总分 + 排序）

## 禁止事项
- 不涉及具体战术与武器操作
