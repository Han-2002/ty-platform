# 任务分解与分派

## 步骤
1. 明确任务目标与约束。
2. 拆分为可独立执行的子任务。
3. 依据席位能力与负载分派。
4. 跟踪执行并汇总结果。

## 检查清单
- [ ] 子任务相互独立且覆盖完整
- [ ] 分派目标具备所需能力

## 输出格式
- 任务分解清单（子任务 + 分派对象 + 时间节点）

## 禁止事项
- 不越权分派、不编造能力
