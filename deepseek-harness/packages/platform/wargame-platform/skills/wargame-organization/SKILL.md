# 兵棋推演组织

## 步骤
1. 成立推演组，明确总导演、参谋、保障等席位及职责。
2. 依据活动目标确定推演阶段（准备/方案拟制/推演验证/执行/复盘）。
3. 制定推演计划，明确各阶段时间节点与交付物。
4. 组织预演，校验推演条件与规则一致性。
5. 正式推演并记录全过程，最终汇总复盘。

## 检查清单
- [ ] 各席位职责明确且无重叠遗漏
- [ ] 推演阶段与交付物一一对应
- [ ] 规则与条件在预演中已验证

## 输出格式
- 推演组织方案（角色分工表 + 阶段计划 + 交付物清单）

## 禁止事项
- 不涉及具体战术、武器操作或任何敏感涉密内容
