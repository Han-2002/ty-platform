## Purpose

实现 Agent 的自迭代与自进化闭环：从执行反思中提炼可复用规程并固化为技能，同时严格禁止自动提权，全过程留痕且可回滚。

## ADDED Requirements

### Requirement: 自进化遵循反思提炼验证固化闭环

系统 SHALL 实现 反思 → 提炼 → 验证 → 固化 的自进化闭环；任务完成后 MUST 触发复盘，并 MUST 能从中提炼可复用经验固化为新技能。

#### Scenario: 任务复盘后提炼出候选技能

- **WHEN** 一个席位完成一项任务并执行复盘
- **THEN** 系统 MUST 产出可供提炼的反思结论，并能将其转化为候选技能条目进入验证环节

### Requirement: 自进化产物强制最低密级且禁止自动提权

系统 MUST NOT 通过自进化提升任何权限；自进化产生的技能 MUST 被强制设定为 `clearance=1`，无论其来源任务的密级高低。

#### Scenario: 高密级任务产出的新技能仍为最低密级

- **WHEN** 一次密级为 4 的任务经复盘提炼出新技能
- **THEN** 该新技能 MUST 被赋予 `clearance=1`，且 MUST NOT 继承该任务的密级

### Requirement: 自进化产物必须校验危险指令

系统 SHALL 对自进化产物执行危险指令校验；命中危险指令的产物 MUST 被拒绝固化。

#### Scenario: 含危险指令的产物被拒绝固化

- **WHEN** 提炼出的候选技能包含被判定为危险的指令
- **THEN** 系统 MUST 拒绝将其固化，并记录拒绝原因

### Requirement: 自进化全过程留痕且可回滚

系统 SHALL 记录自进化全过程的变更痕迹，且 MUST 支持将已固化的自进化产物回滚到变更前的状态。

#### Scenario: 已固化产物可被回滚

- **WHEN** 某自进化技能已被固化，随后管理员执行回滚
- **THEN** 系统 MUST 将该技能恢复到固化前的状态，且该回滚动作 MUST 被记录

### Requirement: 自进化只变更规程不变更权限

系统 MUST 仅通过自进化调整作业规程内容，且 MUST NOT 通过自进化修改任何角色、密级或授权配置。

#### Scenario: 自进化不触碰权限配置

- **WHEN** 一次完整的自进化流程执行完毕
- **THEN** 角色定义、密级设定与技能授权配置 MUST 与执行前保持完全一致

### Requirement: 自进化产物写入独立目录

系统 SHALL 将自进化产物写入独立的运行时目录，该目录 MUST 与手写技能库目录隔离，且 MUST NOT 污染版本控制。

#### Scenario: 产物落在独立目录且不与手写库混用

- **WHEN** 自进化固化一个新技能
- **THEN** 该技能 MUST 被写入独立运行时目录，且手写技能库目录中 MUST NOT 出现该产物
