# agent-runtime Specification

## Purpose
为每一个席位提供彼此独立的 Agent 运行时，包含外置人格、分层记忆、授权边界与空闲时的主动推送能力。

## Requirements

### Requirement: 每个席位拥有互相隔离的独立运行时

系统 SHALL 为每个席位创建独立的 Agent 运行时，各运行时的记忆、会话上下文与已挂载技能 MUST 相互隔离，一个席位的运行 MUST NOT 影响另一个席位。

#### Scenario: 席位间运行时互不干扰

- **WHEN** 席位 A 在其运行时中产生记忆与会话上下文
- **THEN** 席位 B 的运行时 MUST NOT 能读取到席位 A 的记忆或上下文

### Requirement: 人格外置为文件并按优先级覆盖

系统 SHALL 将席位人格外置为 Markdown 文件，业务人员修改该文件即可调整人格而无需改动代码；人格 MUST 按覆盖优先级 席位级 > 角色级 > 内置默认 进行解析。

#### Scenario: 席位级人格覆盖角色级与内置默认

- **WHEN** 同时存在席位级人格文件、角色级人格文件与内置默认人格
- **THEN** 该席位 MUST 使用席位级人格，且角色级与内置默认 MUST 被忽略

#### Scenario: 缺失高层级人格时逐级回退

- **WHEN** 某席位不存在席位级人格文件，但存在其角色的角色级人格文件
- **THEN** 该席位 MUST 回退使用角色级人格，而不是内置默认

### Requirement: 三层记忆并支持持久化与恢复

系统 SHALL 为每个席位提供工作记忆、长期记忆、情景记忆三层记忆，并 MUST 支持 `persist()` 与 `restore()`，使集群重建后记忆可被召回。

#### Scenario: 集群重建后记忆可召回

- **WHEN** 席位运行时执行 `persist()` 落盘，随后该运行时被销毁并重建
- **THEN** 重建后的运行时执行 `restore()` MUST 恢复到落盘时的三层记忆内容

### Requirement: 权限边界内可用且越权不编造

系统 SHALL 限定席位只能使用其被授权的 Skill 与密级范围内的知识；对越权或不可见内容，席位 MUST 明确说明无法获取，且 MUST NOT 编造内容填补。

#### Scenario: 请求越权知识时明确拒绝而非编造

- **WHEN** 某席位请求超出其密级的知识内容
- **THEN** 该席位 MUST 返回无法获取的说明，且 MUST NOT 生成任何看似真实但实际编造的内容

#### Scenario: 未授权技能不可见

- **WHEN** 查询某席位可用的技能列表
- **THEN** 结果 MUST 仅包含该席位被授权的技能，未授权技能 MUST NOT 出现在列表中

### Requirement: 空闲时主动整理并推送重要信息

系统 SHALL 在席位无任务时自主整理信息，并 MUST 主动向相关席位或人员推送重要提示，而非被动等待指令。

#### Scenario: 空闲席位主动推送重要提示

- **WHEN** 某席位处于无任务状态且识别到需要关注的重点信息
- **THEN** 该席位 MUST 主动生成并推送一条提示消息，且该消息 MUST 被标记为主动提示类型
