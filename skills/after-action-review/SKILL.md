# 推演复盘评估(AAR)

## 步骤
1. 回顾推演目标与实际结果。
2. 分析偏差与关键节点。
3. 提炼可复用经验与教训。
4. 形成改进项与后续行动建议。

## 检查清单
- [ ] 复盘覆盖目标、过程、结果三方面
- [ ] 每条经验均可追溯来源

## 输出格式
- 复盘报告（结果对比 + 经验教训 + 改进项）

## 禁止事项
- 不涉及具体战术细节与涉密内容
