# 方案拟制

## 步骤
1. 明确任务与目标。
2. 研判当前态势与约束条件。
3. 提出多套候选方案。
4. 评估比较并择优上报。

## 检查清单
- [ ] 候选方案数量满足要求
- [ ] 每套方案含目标、步骤与资源

## 输出格式
- 方案文本（任务 + 态势 + 候选方案 + 择优结论）

## 禁止事项
- 不涉及具体战术与武器操作
